# PPT Agent

一个用于学习 Python Agent 技术栈的 PPT 生成项目。目标是让用户通过对话提供主题和资料、确认大纲及模板，最终生成可编辑的 PPTX。

项目仍在开发中。目前已实现部分文件处理和 PPT 工具，完整的对话大纲编辑和 PPT 自动制作流程尚未接通。`frontend/` 提供独立静态界面演示，尚未接入后端；启动方式见 [前端说明](frontend/README.md)。

## 产品目标

1. 用户输入主题和要求，可上传参考资料，也可使用联网搜索。
2. 内容智能体收集、筛选资料并生成带来源的大纲；信息不足时向用户提问。
3. 用户通过对话调整大纲，或在未来的前端界面手动修改、合并和排序，然后确认结果。
4. 用户从模板列表选择 PPTX；系统分析模板，不明确或缺少需要的页面时请用户决定如何处理。
5. 制作智能体根据确认的大纲和模板生成 PPTX，目标为 8–12 页，包含封面、目录、内容和来源等页面。
6. 用户查看成品后，可以提出修改意见，系统按问题类型继续处理。

这些是产品目标，不代表完整流程已经接通。当前版本以一次性任务为主，不建设多项目、历史会话和数据库。

## 技术路线

| 技术 | 计划承担的职责 | 当前情况 |
| --- | --- | --- |
| FastAPI | 提供后端 HTTP 接口 | 基础接口已实现 |
| LangChain | 内容智能体、模型调用与工具接入 | 模型适配与部分工具已实现，智能体流程待接入 |
| DeepSeek Harness Python SDK | 制作智能体及其运行时 | 依赖已声明，制作智能体待接入 |
| LangGraph | 编排智能体、人工反馈和流程路由 | 待接入 |
| LangSmith | 模型调用追踪和调试 | 配置已预留，完整工作流追踪待验证 |
| python-pptx | 读取、检查和生成 PPTX | 已实现基础处理能力 |

当前项目要求 Python 3.13 或更高版本，使用 [uv](https://docs.astral.sh/uv/) 管理依赖。具体依赖版本以 `pyproject.toml` 和 `uv.lock` 为准；Harness SDK 当前使用预发布版本。

## 开发进度

目前已具备的基础能力包括：

- 聊天接口接收消息、可选参考文件和模板标识，读取并返回文件内容；当前不调用 AI。
- 通过 RustFS 列举模板，并根据所选对象标识下载和解析模板。
- 提供资料检索、网页搜索与读取、技能发现与读取、模板检查和 PPT 生成等独立工具。
- 支持依据指定模板页面及元素计划生成 PPTX，包含文本、图片、表格、列表和常见图表等基础内容；媒体播放和不同办公软件的兼容性仍需实际验证。
- 提供 PDF 页面渲染、OCR 和模板视觉分析等基础模块，尚未串成完整的自动生成流程。

接下来主要完成内容智能体及工具调用、LangGraph 编排与统一用户提问、Harness 制作智能体、前后端交互和端到端验证。详细状态见 [开发任务列表](docs/开发任务列表.html)。

## 本地启动

在 Windows PowerShell 中进入项目目录，安装依赖：

```powershell
uv sync --locked
```

首次运行时，如项目根目录还没有 `.env`，可从示例创建，再按需要填写配置。**已有 `.env` 时不要执行复制命令，以免覆盖现有配置。**

```powershell
Copy-Item .env.example .env
```

启动服务：

```powershell
uv run --locked --no-sync python main.py
```

默认监听 `127.0.0.1:8000`，可在 `.env` 中设置 `APP_HOST` 和 `APP_PORT`。启动后访问 `http://127.0.0.1:8000/docs` 查看接口说明。联网搜索默认使用Tavily，可在 `.env` 通过 `WEB_SEARCH_PROVIDER=searxng` 切换；联网搜索、RustFS 模板和文档转换等能力需要分别配置对应服务；未配置相关服务不等于这些功能可用。网页浏览器备用读取需要本机安装 Microsoft Edge，通过 `WEBPAGE_BROWSER_FALLBACK` 控制，详见接口调试说明。
