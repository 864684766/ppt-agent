# 全系统日志使用说明

更新日期：2026-11-04。日志是系统基础设施，不是Agent工具或某个业务模块的专属能力。

## 配置

在项目根目录.env配置：

```dotenv
LOG_LEVEL=INFO
LOG_OUTPUT=both
```

LOG_LEVEL必须大写，可选DEBUG、INFO、WARNING、ERROR、CRITICAL；记录该级别及更严重的记录，例如WARNING包含WARNING/ERROR/CRITICAL。缺失默认INFO。

LOG_OUTPUT必须小写，可选file（仅文件）、console（仅控制台标准错误stderr）、both（两者），缺失默认both。console不创建日志目录或文件，但不会删除已有日志文件。修改配置后重启服务或重新运行独立脚本/测试，不支持.env自动热更新。系统环境优先于.env，空值或非法值由Settings报错。

常用组合：本机调试用DEBUG + both；只保留问题日志用WARNING + file；Docker通常用INFO + console，再由容器平台收集stderr。Docker镜像及部署暂未在本任务实现。

## 初始化与调用

config/logging_config.py只接收显式参数，不自行读取环境变量。服务在FastAPI lifespan初始化一次；独立测试或脚本由入口读取Settings再初始化。导入业务模块不创建日志文件。

```python
# 仅放在应用、独立脚本或测试的入口。
settings = Settings()
configure_logging(
    directory=PROJECT_ROOT / "log",
    level=settings.log_level,
    output=settings.log_output,
)
```

各功能模块统一使用标准库logging，不导入Settings或自行创建处理器：

```python
import logging

logger = logging.getLogger(__name__)

# 在实际执行步骤处记录；__name__标明来源模块。
logger.info("开始生成PPT。")
logger.warning("模板缺少目录布局。")
```

不要写入真实密钥、配置全文、敏感资料或上游异常原文。日志模块不自动脱敏。print不是日志，不受LOG_LEVEL或LOG_OUTPUT控制，也不会自动写入日志文件。

## 文件与控制台

例如log/ppt-agent-2026-11-04.log、log/ppt-agent-2026-11-05.log。日期使用运行环境本地时区，容器部署时需按预期设置时区。configure_logging返回的是初始化当日的路径，处理器会随记录日期自动切换；没有新日志时无需定时生成空文件。历史旧版ppt-agent.log不会自动搬迁或删除。

启用文件时写入项目log/ppt-agent-YYYY-MM-DD.log，目录不存在自动创建；UTF-8，每个本地日期一个文件，跨天首条日志自动切换，同日重启追加；不按大小拆分，不自动删除历史文件。格式为时间、级别、模块名、消息。不同模块共享文件，以模块名区分来源。log/已加入Git忽略规则。

重复初始化替换并关闭本项目处理器，避免重复写入；切换到console停止写文件但保留历史文件。本模块不删除pytest/Uvicorn已有处理器，因此LOG_OUTPUT=file不保证pytest或Uvicorn完全不向控制台输出。只有传播到根logger且达到级别的记录进入本项目处理器；独立logger及子进程需另行接线。当前按日写入只用于单进程，多Worker不承诺安全共享同一文件。

pytest的--log-cli-level独立控制pytest自己的控制台处理器，可能与本项目console同时显示；检查本项目目标时可不额外开启pytest实时日志。-s输出测试print也不受LOG_OUTPUT控制。

## FastAPI生命周期

main.application_lifespan使用@asynccontextmanager声明异步上下文。FastAPI启动时进入，执行yield前的配置；yield将控制权交还框架处理请求，关闭时恢复执行后续清理。这里不产生HTTP响应，也不是每次请求重新初始化。当前yield后没有清理步骤，未来资源可用try/finally管理；不能删掉yield，否则不再满足异步上下文管理器协议。
