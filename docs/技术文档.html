架构与职责

FastAPI / 传输层   接收问题、附件和模板选择；当前只读取并返回JSON
        ↓ 未来接线
LangGraph          全局路由、状态、人工反馈和恢复（未实现）
        ├─ LangChain 内容子智能体：资料搜索/读取、筛选、来源和大纲（未实现）
        └─ Harness 制作子智能体：模板分析、映射、页面制作及检查（未实现）
                   ↓ 调用模型可选工具
domain + integrations   独立业务规则、协议、文件处理、模型与外部服务适配

LangChain和Harness的模型工具入口由各自运行时接入；MCP客户端/适配是基础设施模块，MCP服务暴露的能力可成为模型工具。技能指导选择流程、规则和脚本，实际工具执行由运行时处理。Agent工具的描述和参数Schema供模型决定调用；普通Python方法不等同于Agent工具。

独立网页资料收集实验：LangGraph调度查询Agent、检查Agent；查询Agent先理解用户意图并保留限定，再由模型生成搜索词，再调用宿主注入的search_web工具，检查Agent按标题摘要筛选并反馈。图每轮均不指定引擎，由SearXNG服务器选择，结果不足时根据反馈调整搜索词；独立合并模块按完整URL去重，分别累计正式和备用候选，正式候选达到目标数量或次数用尽时结束；不足时可由调用方选择备用候选编号，已选备用与正式结果分开保存；当前没有真实交互接口或恢复。图节点使用实例内存检查点，可凭调用方任务编号恢复失败节点；重启或销毁实例后丢失，每批检查节点结束后保存进度；超限批次拆分，单条超限标记未检查。图的读取和整理节点可读取正式候选并让模型整理带候选编号的要点及缺口，读取失败单独返回；尚未接入交互、资料登记、chat或大纲生成，且不保证来源权威；引擎可用性需真实验证。

资料收集图依赖 domain/web/research_agents_contract.py 的查询和检查协议；真实Agent或测试替身只需实现对应方法，无需继承具体实现。这些协议只定义调用边界，不创建模型或网络连接。

目标流程（尚未形成闭环）

用户主题 / 要求 / 可选文件、模板
       ↓
LangChain内容Agent：资料计划 → 本地读取 或 联网搜索/筛选 → 大纲
       ↓                     ↘ 信息不足 → ask_user → 用户回答
用户对话修改或前端手动编辑并确认
       ↓
LangGraph交接 → Harness制作Agent：结构 + 可选视觉 → 页面角色 / 内容映射
       ↓                     ↘ 模板缺失或风格不清 → ask_user → 用户回答
按需 complete_template / create_template_page → build_presentation
       ↓
按需 check_presentation → 输出PPTX / 接收修改 → 按内容或模板问题分派

这是职责说明，不是强制工具调用顺序。人工反馈、真实大纲、模板角色识别和Agent分派尚未接线；前端手动编辑后的结果由后端接收，不由后端代替前端做局部拖拽合并。

当前API与资源

  • GET /health：健康检查。
  • GET /ppt-agent/v1/templates：RustFS/S3的PPTX列表；模型工具不是HTTP接口。
  • POST /ppt-agent/v1/chat：消息、可选file及template_key；返回解析结果JSON。template_key来自列表object_key；无附件允许只传消息；不调用AI。

API调试、Postman字段、错误及资源配置见接口说明与模板列表说明。不创建Postman工作区或集合。

模板、媒体及质检

inspect_template返回实际页、母版、版式、对象和占位符事实，不单凭名字判断封面。测试和宿主以实际页号/shape_id构造页面计划；build_presentation按该顺序复制参考页，混排文字、图片、媒体、表格、列表和基础图表。图片、MP4、MP3按宿主编号传字节；聊天上传尚未登记到生成器。视频和音频嵌入采用实验性接口，播放需WPS/PowerPoint验证。

工具不自动选择页面、处理全部复杂图形、消除重叠或核实事实。check_presentation当前检查大小、基础包结构、可解析、页数及无可提取文字页提示；大纲覆盖、来源、视觉、真实Office打开未实现。passed仅表示必过基础规则通过。

长任务、追踪与安全边界

模型、搜索、网页和Gotenberg各有请求超时；本地同步PPT操作使用线程，取消等待不保证线程停止。缺少工作流总预算、进度、取消后的产物管理和重启恢复；随Harness、LangGraph与工作流API阶段开发、测试。日志记录生命周期、操作关联及安全异常位置，不记录密钥或资料正文，见日志说明。LangSmith配置不等于业务追踪已经接入。

风格与输入

图表支持常用轴线、刻度、网格线和图例配置；表格支持颜色，具体能力与未支持项见生成调试说明。未来由Agent提示词/技能结合模板分析提供具体配色和数据，当前不自动保证风格匹配或防止溢出。
