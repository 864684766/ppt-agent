架构与职责

FastAPI / 传输层   接收问题、附件和模板选择；当前只读取并返回JSON
        ↓ 未来接线
LangGraph          全局路由、状态、人工反馈和恢复（未实现）
        ├─ LangChain 内容子智能体：资料搜索/读取、筛选、来源和大纲（未实现）
        └─ Harness 制作子智能体：模板分析、映射、页面制作及检查（未实现）
                   ↓ 调用模型可选工具
domain + integrations   独立业务规则、协议、文件处理、模型与外部服务适配

LangChain和Harness的模型工具入口由各自运行时接入；MCP客户端/适配是基础设施模块，MCP服务暴露的能力可成为模型工具。技能指导选择流程、规则和脚本，实际工具执行由运行时处理。Agent工具的描述和参数Schema供模型决定调用；普通Python方法不等同于Agent工具。

独立网页资料收集实验：LangGraph调度查询Agent、检查Agent；查询Agent先理解用户意图并保留限定，再由模型生成搜索词，再调用宿主注入的search_web工具，检查Agent按标题摘要筛选并反馈。图每轮均不指定引擎，由SearXNG服务器选择，结果不足时根据反馈调整搜索词；独立合并模块按完整URL去重，分别累计正式和备用候选，逐页读取并按有效来源目标和明确缺口决定继续或结束；不足时可由调用方选择备用候选编号，已选备用与正式结果分开保存；当前没有真实交互接口或恢复。图节点使用实例内存检查点，可凭调用方任务编号恢复失败节点；重启或销毁实例后丢失，每批检查节点结束后保存进度；超限批次拆分，单条超限标记未检查。图的读取和整理节点可读取正式候选并让模型整理带候选编号的要点及缺口，读取失败单独返回；尚未接入交互、资料登记、chat或大纲生成，且不保证来源权威；引擎可用性需真实验证。

资料收集图依赖 domain/web/research_agents_contract.py 的查询和检查协议；真实Agent或测试替身只需实现对应方法，无需继承具体实现。这些协议只定义调用边界，不创建模型或网络连接。

目标流程（尚未形成闭环）

用户主题 / 要求 / 可选文件、模板
       ↓
LangChain内容Agent：资料计划 → 本地读取 或 联网搜索/筛选 → 大纲
       ↓                     ↘ 信息不足 → ask_user → 用户回答
用户对话修改或前端手动编辑并确认
       ↓
LangGraph交接 → Harness制作Agent：结构 + 可选视觉 → 页面角色 / 内容映射
       ↓                     ↘ 模板缺失或风格不清 → ask_user → 用户回答
按需 complete_template / create_template_page → build_presentation
       ↓
按需 check_presentation → 输出PPTX / 接收修改 → 按内容或模板问题分派

这是职责说明，不是强制工具调用顺序。通用ask_user方法已接入网页资料图，支持内存检查点暂停及工作流层恢复，询问内容已由/chat/stream返回，回答HTTP接口尚未实现；真实大纲、模板角色识别和Agent分派尚未接线；前端手动编辑后的结果由后端接收，不由后端代替前端做局部拖拽合并。

当前API与资源

  • GET /health：健康检查。
  • GET /ppt-agent/v1/templates：RustFS/S3的PPTX列表；模型工具不是HTTP接口。
  • POST /ppt-agent/v1/chat/stream：消息、可选file及template_key；返回联网网页研究结果、询问及可选附件和模板解析结果。template_key来自列表object_key；无附件允许只传消息；附件暂未参与模型分析。

API调试、Postman字段、错误及资源配置见接口说明与模板列表说明。不创建Postman工作区或集合。

模板、媒体及质检

inspect_template返回实际页、母版、版式、对象和占位符事实，不单凭名字判断封面。测试和宿主以实际页号/shape_id构造页面计划；build_presentation按该顺序复制参考页，混排文字、图片、媒体、表格、列表和基础图表。图片、MP4、MP3按宿主编号传字节；聊天上传尚未登记到生成器。视频和音频嵌入采用实验性接口，播放需WPS/PowerPoint验证。

工具不自动选择页面、处理全部复杂图形、消除重叠或核实事实。check_presentation当前检查大小、基础包结构、可解析、页数及无可提取文字页提示；大纲覆盖、来源、视觉、真实Office打开未实现。passed仅表示必过基础规则通过。

长任务、追踪与安全边界

模型、搜索、网页和Gotenberg各有请求超时；本地同步PPT操作使用线程，取消等待不保证线程停止。缺少工作流总预算、进度、取消后的产物管理和重启恢复；随Harness、LangGraph与工作流API阶段开发、测试。日志记录生命周期、操作关联及安全异常位置，不记录密钥或资料正文，见日志说明。LangSmith配置不等于业务追踪已经接入。

风格与输入

图表支持常用轴线、刻度、网格线和图例配置；表格支持颜色，具体能力与未支持项见生成调试说明。未来由Agent提示词/技能结合模板分析提供具体配色和数据，当前不自动保证风格匹配或防止溢出。

网页图结束后由程序汇总检查报告：来源数量、模型缺口、搜索和读取失败、截断及未完成检查；报告不包含搜索feedback，不代表事实核验，也尚未接入前端询问卡片。

网页候选检查模型连接中断时仅重试当前模型请求，最多两次；超时和其他错误沿既有路径处理，失败不视为无资料。模型SDK自动重试仍关闭。

候选检查模型超时时停止收集并返回interrupted和model_timeout，保留已完成结果与未检查候选；当前不提供该结束状态的恢复重试。查询和正文整理发生未单独处理的超时由网页图边界转换为中断报告。

网页读取后逐篇提炼要点：单页正文只发送给单页提炼模型，图状态保存网页元数据、正文指纹和单页要点，不保存正文。每次加入要点后以累计要点检查充分性并合并，停止时保留最后一次合并结果；截断单独报告，不自动续读。单页提炼发生模型输出长度超限时，以更精简要求最多重试一次；再次失败则向调用方抛出，不伪装为空网页。内容检查以结构化问题区分内容缺口、来源冲突、版本问题和用户指定的来源要求；仅是基于现有要点的模型判断，不保证准确，也未接入询问卡片。

网页提炼为空时不重复调用汇总，仍记录截断和跟进链接。累计汇总输出超限时，图以interrupted和summary_length_exceeded停止，保留单页要点及上次成功汇总；报告明确检查未完成，不宣称来源不足或充分。该停止结果目前不能用resume重试，进程退出不持久化。

网页资料不足时，图内finalize节点先生成报告及稳定waiting_question，ask节点调用通用ask_user暂停。模型超时或汇总输出超限返回interrupted，不进入资料补充询问。选项代码为provide_materials、use_current（仅有已整理要点时）和end_conversation；备用候选保留但逐项选择暂未接入。调用方持有同一个工作流实例和thread_id，可通过answer方法恢复；提供资料仅转换为needs_materials，文件处理与HTTP回答接口尚未接线。use_current提示最终PPT可能少于8–12页，尚未生成PPT或大纲。

2026-11-24职责整理：网页研究图负责节点调度与检查点，结束状态和问题生成由domain/web/research_outcome.py处理，用户决定由domain/web/research_decision.py处理，同站后续链接的筛选由domain/web/research_follow_links.py处理；报告的内容、读取、检查问题分别聚合。文件解析、PPT检查与绘制仍由各自原有模块负责，拆分仅改变内部步骤，不改变HTTP或工具契约。

本次验证：资料、模板检查、图表、日志、存储和真实PDF OCR等29项通过；真实搜索与网页工具5项通过，真实模型研究流程1项通过，PPT生成2项通过。补全测试所选真实模板为15页、测试固定目标10页，构造空补页计划后被输入校验拒绝；PDF页渲染测试缺少指定的预生成PDF。另以真实生成的PPTX和PDF验证页面复制与渲染；不能替代指定文件的人工验收。

/chat首次请求使用应用生命周期管理的网页研究运行时，复用现有查询、检查及整理Agent，进程内检查点在服务退出时失效；尚无HTTP回答接口。请求包含附件时只解析并回显，不参与资料研究。本阶段每次/chat都联网搜索；仅文件分析后续接入。

POST /ppt-agent/v1/chat/stream 使用SSE推送实际网页研究阶段与最终JSON；同一业务选择公开字段，传输层仅编码事件。断开时取消任务，线程内文件解析可能继续；可选发送LangChain标准reasoning内容块；默认关闭且供应商适配器不提供时没有事件。旧非流式/chat已删除；HTTP回答和前端渲染未实现。

LLM_SHOW_THINKING控制SSE是否展示LangChain标准推理块，不控制模型是否推理；开启时使用模型流式回调并保留结构化输出校验。ChatOpenAI默认不保留第三方推理字段；当前适配器将reasoning_content转为标准reasoning块，依赖锁定版本的内部转换钩子，升级时必须复验。应用日志不记录推理正文。

FileExtractionAgent支持独立文件提炼；WebpageExtractionAgent负责单页提炼，MaterialSummaryAgent负责网页与文件要点汇总，网页工作流已接入；文件、文本及用户网址分流尚未接入。

资料图按正文整理中的来源数与模型报告的明确缺口判断停止；未达标优先读取剩余候选、跟进已读页面中被模型选择的真实同站链接，再依据缺口重新搜索，受搜索和读取次数上限约束。HTTP用户回答、上传文件后恢复尚未接入；有效来源属于模型判断，不等于事实核验。

网页汇总按单次输出预算分批：每批要点数为 min(20, max(1, LLM_MAX_TOKENS // 1024))。1024 是经验估算，并非模型分词或可用上下文的精确测量；输出预算可能包含推理和 JSON。分批后再整体汇总检查重复与缺口，批次超限会二分重试；单条或最终整体汇总仍超限时中断并保留单页要点及上次汇总。整体汇总未完成时不能判断资料充分。实际模型请求直接使用 LLM_MAX_TOKENS，不再强制至少 4096。

文件提炼Agent已实现独立调用：接收问题、文件名和文件字节，先通过注入的DocumentFileReader校验并按格式解析；也可接收已解析的DocumentContent。然后按正文块及4000字符上限分批，超长块拆分并沿用块编号；模型只提炼相关要点，程序验证编号并保留读取警告与无文字页。块编号只属于本次解析，文件名不是资料库ID。批次要点可能重复，跨批整合和充分性判断留待汇总阶段；空结果不等于已确认文件无关。已识别的模型超限、连接失败、超时及结果无效返回中断，其余异常上抛；尚未接入/chat/stream。

文件提炼批次输出超限时按正文块或块内文字二分，最多拆六层；模型输出格式或来源编号无效时当前批次重试一次，仍失败则有界拆分；达到拆分上限后返回 interrupted。日志只记录 schema、type 或 unknown_block 分类，不记录模型输出或正文。连接中断、超时或拆分后仍超限时返回 interrupted、已成功要点及已处理字符数。未完成正文不算成功；当前支持单实例内恢复和连接/超时重试；未支持HTTP或持久化恢复。提示词要求按问题归并同类要点，但实际信息保留和语义去重仍需人工评价；读取器规模限制仍生效。

文件提炼的模型连接或超时失败最多重试当前批次两次，分别等待1、2秒。仍失败时返回resume_id；同一Agent实例的resume方法消费该编号，继续失败批次和待处理队列，完成批次不重做。重复恢复失败返回新编号；进程退出或实例销毁后失效，不支持HTTP恢复、持久化或自动清理未恢复任务。DOC使用Gotenberg转换为PDF再提取，转换后页码和版式可能变化。

通用资料汇总：网页及文件要点通过material_summary_inputs转换，文件未完成时拒绝作为完整输入；每条要点携带调用方分配的唯一编号及网页候选或文件块位置。模型只引用要点编号，程序校验编号并通过references_for还原来源；模型判断不等于事实核验。网页工作流已接入该Agent并映射回原响应契约；文件汇总尚未接入聊天接口。分批后最后一次整体汇总超限仍会中断。

职责边界：WebpageExtractionAgent只提炼单篇网页并选择页面真实链接；FileExtractionAgent只读取和提炼单份文件；MaterialSummaryAgent负责跨批及跨来源要点汇总。网页提炼规则和JSON格式合并于web_research_page.md，输出超限重试提示词单独维护。

目录按职责分组：agents/web负责网页查询、检查和单页提炼；agents/materials负责文件提炼和通用汇总；prompts按web/materials/templates分组；workflows/web、interaction、materials分别放网页图、通用询问和资料汇总编排。MaterialCollectionWorkflow编排网页和可选文件的提炼、汇总和询问；尚未接入/chat/stream及HTTP用户回答。

网页研究run新增defer_user_question，默认false并保留原ask_user暂停；true时网页资料不足仅返回insufficient及报告、不生成用户问题、不暂停，供未来上层合并文件后再判断。此选项尚未由/chat/stream启用；网页收集失败与正文读取失败详情仍在报告中。

文件Agent返回FileProcessingReport描述校验、读取或提炼阶段；已知FileUploadError、DocumentReadError转为failed及安全说明，模型超时等返回interrupted并保留部分要点。空页面和无要点不等同无关；未知读取或单批提炼异常返回固定错误并记录安全异常位置；取消与输入错误不转换。报告由上层综合，未直接输入汇总模型；/chat/stream尚未接入文件Agent。

网页图run/resume执行异常在图边界记录安全位置并返回interrupted和workflow_failed报告，保留最近检查点；分类为模型连接、模型超时或执行失败，不将异常原文作为资料交给汇总模型。调用前参数错误、取消和检查点本身不可用不保证转换；网页各节点此前捕获的超时、搜索错误和汇总超限仍保持已有处理方式。统一网页/文件报告已接入资料工作流，尚未接入HTTP。

MaterialCollectionWorkflow现编排网页（延后询问）、可选一份文件、通用汇总、最终报告与ask_user；使用内存LangGraph检查点。已引用的网页及文件来源数量达到目标且无内容问题才完成；不足暂停，存在要点时提供use_current，否则仅补充或结束；use_current提示页数可能不足。网页、文件或汇总未完成返回interrupted，保留阶段报告；图未分类故障也返回安全中断，未能计算的来源数量为null，尚未实现补充资料后处理、HTTP恢复或持久化；仅文件分支可不联网。

RequestAnalysisAgent使用现有模型分析用户消息、附件是否存在和可选联网约束，生成来源模式与执行顺序、是否询问及原因；Pydantic检查组合，程序检查附件事实和allow_web=false。自然语言限制仍依赖模型理解，实际执行前必须重新核对用户明确约束；已接入资料图，尚未接入HTTP。

需求分析对调用失败返回RequestAnalysisResult安全状态；输入无效、模型超时、连接失败、结果无效和未知异常分类处理，失败plan为null；安全日志不记录正文和异常原文。Agent已接入资料图，尚未接入HTTP；前端错误事件需接线时单独处理，不能认为已有前端保障。

资料工作流先分析需求，再按计划选择仅文件、仅网页、两者并行或文件后网页。文件后网页把文件要点传给网页流程，文件处理失败或无要点时不搜索。需求不明确时ask_user暂停，文字答复后重新分析；缺少附件时询问，但上传附件并恢复尚未接线。分析失败返回interrupted和analysis错误分类，不进入收集或资料不足询问。allow_web=False为明确禁止联网。内存检查点仅在实例存续期间有效；尚未接入聊天接口。
