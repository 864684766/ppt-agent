未完成任务与建议顺序

  1. 最小 LangChain Agent：先接一个实际工具，验证真实模型选择、调用参数、工具结果及错误反馈；单独记录测试，与工具单测区分。
  2. LangGraph 与通用人工反馈：最小编排和 ask_user；用户收到问题、输入真实回答后恢复。确定问题关联、取消、重试和等待期间资源管理；先验证当前进程内行为。
  3. 内容子智能体：问题、上传资料和搜索结果按来源接入资料工具；制定资料搜集方案、选用技能和提示词、生成并对话修改大纲；前端手动合并和编辑后的结果由后端接收、校验和确认。
  4. Harness SDK 接入：验证 Python SDK、百舸代理模型、工具/MCP、技能资源及脚本、取消/错误与提问桥接；与LangChain/ LangGraph共享语义不代表API相同。
  5. 模板和制作智能体：组合结构、渲染和视觉分析，判断页面角色/槽位，不能确定时询问；根据用户选择复用参考页或补全页面，把确认内容映射到模板后调用生成和检查工具。素材编号、产物登记与文件交付需接线。
  6. 工作流API与前端契约：问题和附件、模板选择、大纲对话与确认、用户回答、任务进度、取消、PPTX下载、生成后修改；在现有接口基础上设计，当前还未实现。
  7. 质量和完整验收：对大纲覆盖、来源准确性、视觉版式、文字溢出、模板残留、WPS/PowerPoint打开及视频/音频播放分别验证；检查工具的这些扩展规则目前未实现，不把基础检查通过当作产品验收通过。
