第一阶段：完整后端闭环

任务工作内容完成标准状态
01 环境与依赖检查 Python、虚拟环境、Windows 依赖，确认并锁定兼容版本，建立不含密钥的配置示例。查询最新版本并验证兼容性；依赖安装成功后输出实际版本、锁文件与启动方法；不改写现有密钥。已完成
02 FastAPI 基础建立应用入口、健康检查和基础错误处理。本机可启动；健康检查与 API 文档可访问。未开始
03 模型配置对接用户已有百舸模型配置，提供按任务选择模型的配置入口。能通过项目配置发起一次测试调用；不重复评判用户已确认的代理基础能力；密钥不进入日志。未开始
04 大纲数据模型定义项目、对话、大纲条目、版本及内存状态。可表达页类型、标题、要点、顺序和版本；验证不合法输入。未开始
05 大纲对话与编辑主题生成大纲；多轮对话修改；接口直接修改、增删、排序、合并与拆分。对话和手动操作更新同一份大纲，冲突不静默覆盖；可确认大纲。未开始
06 文件和简洁模板上传 PPTX，保存在本地项目目录；制作一个简单内置模板。完整和残缺模板均可上传；文件大小与类型检查生效。未开始
07 Python 模板分析解析母版、版式、占位符和样例页；验证一种 Windows 预览渲染方式。返回结构与预览或明确错误；记录字体和模板兼容问题。未开始
08 MCP 工具服务将模板分析等 Python 模块封装为 MCP 工具，LangChain 与 Harness 分别接入。两端可发现并调用指定工具；验证 Windows 进程、取消、错误和文件范围。未开始
09 LangChain 模板识别结合结构、文本和可用视觉能力，生成角色建议、槽位、依据及缺失项。能分析完整和残缺模板；不确定项不会伪装为确定结论。未开始
10 LangGraph 人工反馈识别结果返回图状态；用户回答、映射确认或选择补充／AI 补全。运行进程内可暂停与继续；确认后的映射可供后续节点读取。未开始
11 Harness 接入用 Python SDK 接入百舸模型配置、任务输入和 MCP 工具；验证提问、取消和错误。可接收 LangGraph 交付的确认结果并完成受控子任务；如遇兼容问题先记录并解决。未开始
12 PPTX 生成Harness 使用确认的大纲和模板映射调用 Python 工具；残缺模板按用户选择补全。生成 8–12 页可打开 PPTX，含封面、目录、内容和来源页；主要文本可编辑。未开始
13 闭环验证通过 API 执行主题对话、大纲编辑、残缺模板反馈、生成和下载。完整与残缺模板至少各验证一次；报告局限和操作步骤。未开始
