阅读约定

  • Pydantic Input负责工具参数Schema与边界校验；TypedDict Output只描述返回字典，不自动校验。
  • dataclass是内部结构；MaterialSummary和MaterialFragment创建时执行字段校验，其他内部结果不因类型标注就自动校验。
  • None对外序列化为null；字符数不是字节数或token数，偏移从0开始，原文件页码从1开始。
  • 既有资料实体仍有project_id和version字段：目前是已有工具契约的内部范围/一致性约束，不代表正在建设多项目或历史版本系统，也不要求前端传project_id。
  • 来源编号source_id、正文块block_id和候选网页candidate_id用途不同；搜索或抓取成功不等于已登记资料。没有新增数据库或全局Store。

2. 资料工具：按操作查输入输出

工具 list_materials

定义：models/materials/list_materials_contract.py。查询宿主目录快照；不扫描硬盘、不上传或解析文件。

ListMaterialsInput

字段Python类型必填 / 默认值含义与约束
originLiteral['all', 'uploaded', 'web']'all'筛选来源类型：all=当前项目全部已登记业务资料；uploaded=用户上传的业务参考文件；web=已抓取并登记的网页正文。省略时为all。这里不会联网搜索，也不包含PPT设计模板或技能资源。例如只看上传文件时填uploaded。
name_containsstr''仅按资料显示名称做字面子串过滤，不搜索正文，不是正则表达式。例如填劳动可匹配劳动合同法.pdf。忽略首尾空白和大小写，最多200字符；省略或填空字符串表示不按名称过滤。 字段约束：最大长度 200。
offsetint0在过滤并排序后的结果中跳过多少条，从0开始，必须为非负整数。首次查询省略或填0；继续翻页时填上次返回的next_offset，并保持同样的来源/名称过滤条件。next_offset为null时停止翻页。例如上次next_offset为20，本次填20。 字段约束：≥ 0。
limitint20本次最多返回多少条资料摘要，必须为1至100的整数，默认20。这是目录条数，不是正文长度、页码或检索轮数；当total大于当前已返回范围时，通过next_offset继续翻页。例如只需查看最多10条摘要时填10。 字段约束：≥ 1；≤ 100。

MaterialListItem

字段Python类型必填 / 默认值含义与约束
source_idstr返回时提供；非调用入参项目内资料编号，可用于后续检索和引用。
namestr返回时提供；非调用入参资料显示名称，不是本机文件路径。
originLiteral['uploaded', 'web']返回时提供；非调用入参来源类型：uploaded上传文件，web已登记网页。
formatstr返回时提供；非调用入参资料格式名，例如pdf、docx、html。
statusLiteral['pending', 'ready', 'failed']返回时提供；非调用入参解析状态：pending待解析、ready可读、failed解析失败。
versionstr返回时提供；非调用入参资料版本标识，读取时必须与正文版本一致。
urlstr | None返回时提供；非调用入参网页原始地址；上传资料为None（JSON中为null）。
page_countint | None返回时提供；非调用入参原文件总页数；未知为None（JSON中为null）。

ListMaterialsOutput

字段Python类型必填 / 默认值含义与约束
itemslist[MaterialListItem]返回时提供；非调用入参本次返回的资料摘要列表；没有符合条件的资料时为空列表。

next_offsetint | None返回时提供；非调用入参下次目录调用的offset；None表示分页结束，单位是资料条数。

工具 search_materials

定义：models/materials/search_materials_contract.py。在已提供的ready正文中进行字面关键词搜索，不重新联网。

SearchMaterialsInput

字段Python类型必填 / 默认值含义与约束
querieslist[Annotated[str, Field(min_length=1, max_length=200)]]必填必填，1至8个关键词，每个1至200字符。忽略大小写，按字面子串查正文，不是正则或语义搜索；多个词按任意一个命中。例如[经济补偿,解除劳动合同]。同义词需明确列入，不会自动扩展。 字段约束：最小长度 1；最大长度 8。
source_idslist[Annotated[str, Field(min_length=1, max_length=200)]] | NoneNone可选，限定当前项目的来源ID，例如[s01,s02]；省略或null搜索项目内全部ready资料。不能传空列表；指定不存在或未ready的来源会报错，不伪装为无命中。 字段约束：最小长度 1；最大长度 100。
originLiteral['all', 'uploaded', 'web']'all'来源过滤：all=全部，uploaded=上传业务文件，web=已抓取并登记的网页正文。默认all；例如只看上传资料填uploaded。与source_ids共同过滤，不重新联网。

max_chars_per_matchint300每条命中文本最多返回多少个Python字符，50至1000，默认300，不是字节或token。例如填100返回最多100字符；长块围绕最早命中截取，text_truncated表示原块未完整返回。 字段约束：≥ 50；≤ 1000。

工具 read_material

定义：models/materials/read_material_contract.py。读取一个已定位正文块，支持按next_offset续读，不直接读取磁盘原文件。

ReadMaterialInput

字段Python类型必填 / 默认值含义与约束
source_idstr必填必填，当前项目已登记资料的来源ID，例如s01；来自list_materials或search_materials。不是文件路径、URL或资料名称；不能切换项目。 字段约束：最小长度 1；最大长度 200。

max_charsint2000本次最多返回的Python字符数，1至8000，默认2000；不是字节或token。例如填500最多读取500字符，长块通过next_offset续读，不会静默丢掉剩余正文。 字段约束：≥ 1；≤ 8000。

PDF页面渲染模块（2026-11-05）

渲染器创建、测试及后续页面分析使用的内部不可变dataclass；不依赖SDK，不包含磁盘路径，不预设PPT页码或LangGraph状态。详见调试说明。

PdfPageImage

字段类型默认值含义
page_numberint必填，无默认值原PDF中的页码，从1开始；不是模型判断的页码，也不自动等同于PPT页码。
width_pxint必填，无默认值PNG的实际宽度，单位像素（px），不是PPT使用的EMU。
height_pxint必填，无默认值PNG的实际高度，单位像素（px）。
png_bytesbytes必填，无默认值PNG完整文件字节，可由调用方落盘或传给视觉模块；不包含base64前缀。

PdfRenderResult

字段类型默认值含义
pdf_sha256str必填，无默认值本次输入PDF的SHA-256指纹，用于区分不同文件；不是版本管理或真实性证明。
total_pagesint必填，无默认值原PDF总页数；即使只渲染两页，这里仍表示原文件全部页数。
dpiint必填，无默认值本次使用的DPI（每英寸像素数），默认144；越高图片通常越大，不保证识别更准。
imagestuple[PdfPageImage, ...]必填，无默认值按调用方指定的页码顺序保存；pages=None时按PDF原始顺序保存全部页。 tuple是元组，不提供append；图片字节和元组均不可变，适合跨层传递。

参数类型/默认值含义与约束

日志与HTTP诊断字段（2026-11-05）

本组为日志上下文字段和结果摘要，不是models业务实体、持久化Store或LangGraph状态；diagnostics定义并由执行边界创建，只用于诊断，不传给模型作为工具结果。现有业务字段与返回格式不变。

字段/类型默认、约束与单位含义及创建/使用边界
request_id / str默认“-”；HTTP中为服务器生成的UUID十六进制串一次HTTP请求的日志关联号，结束后恢复外层上下文；独立操作无HTTP时为“-”，不是会话ID。
X-Request-ID / HTTP响应头str正常经中间件发送的响应写入；外层框架生成500不保证存在由请求中间件输出，与request_id相同，便于Postman查日志；不采用客户端提供编号。
operation_id、parent_operation_id / str外层无操作为“-”；每次操作随机UUID操作编号在处理器输出时附加；父编号在start消息中记录，连接工具及适配器操作。退出后恢复，非业务版本。
event、operation / str固定开发者定义，无用户输入生命周期start/completed/failed/cancelled或结果事件名；operation为固定操作名，非用户主题。
duration_ms / float格式文本非负，毫秒，通常两位小数墙钟耗时，包括等待；操作完成、失败或取消及HTTP结果时记录，不是token或CPU统计。
error_location / str仅失败时出现；最多5层异常，每层末尾8个栈帧异常类和文件名:行号:函数链；无原异常文本、源码或局部变量，不等于完整traceback。
route、status / str、int或Noneroute未匹配为unmatched；尚未发送响应头时status=None路由模板与已发送HTTP状态，不记录原始URL或查询串；SSE 200不证明模型成功。
response_complete、disconnected / bool初始False是否发送最终响应体；是否经receive观察到http.disconnect。False不证明客户端始终在线。
http_status、service、code上游状态int或None；其余为固定分类文本SDK已知状态、固定服务分类、SSE model_timeout/model_error错误分类；不含上游正文。

结果摘要按模块显式选择：search的query_chars/max_results/returned_count为查询字符数/请求上限/实际条数；webpage的downloaded_bytes/text_chars为下载字节数/正文字符数；chat的chunks/text_chars为可见输出块数/字符数，非严格token数；skills的accepted_count/content_chars为接受技能数/指令字符数；template的slides/layouts/masters/warnings为数量；conversion的input_bytes/output_bytes/timeout_seconds为输入输出字节数/HTTP阶段等待上限秒数；vision的image_bytes/mime_type/page_role/readable_text_count/limitation_count为输入字节/MIME/模型页面分类/可读文字条数/限制条数；PDF的requested_pages为请求页数或all、total_pages/rendered_pages为PDF总页数/实际渲染数，pdf_page为从1起页码，dpi为每英寸像素，width_px/height_px为图片像素尺寸。所有数量为非负整数，无统一业务默认值，仅在对应阶段记录。

网页连接DEBUG字段verify_tls为证书校验布尔开关，max_redirects=5为重定向次数上限；关闭证书校验记WARNING，未知网页编码回退仅记录固定utf-8，不输出网页声明原文。DEBUG模型配置摘要model/timeout_seconds/max_tokens为所选模型名、等待秒数和输出token上限，无密钥或代理地址；这些是日志摘要，不新增环境配置或公开模型字段。time/level/logger等标准字段由logging生成。详情见日志使用说明。
