# RustFS模板资源列表（2026-11-06）

模板与聊天资料分开：前端请求列表，用户选择PPTX，后续再根据选中object_key读取模板用于制作。
当前实现独立GET列表接口；选中后将object_key通过template_key传入chat，已接实际下载和PPTX文字解析。不预览、不保存跨请求选中状态、不做Harness串联。
聊天附件不再有purpose，参数为message、可选file和可选template_key，上传的PPTX作为参考资料读取；所有对话都不调用AI。

## 本机配置

用户提供的S3 API：http://124.71.135.104:8081；桶ppts。
8084/rustfs/console/browser/是管理控制台，不是本项目SDK连接地址。
已在本机.env仅补充上述非敏感地址/桶（已有同名配置不覆盖）。其余按.env.example填写：

```dotenv
S3_ENDPOINT_URL=http://124.71.135.104:8081
S3_TEMPLATE_BUCKET=ppts
S3_ACCESS_KEY_ID=
S3_SECRET_ACCESS_KEY=
S3_REGION=us-east-1
S3_TIMEOUT_SECONDS=20
```

请在本机.env填写实际Access Key ID和Secret，不需要发到聊天，不传给前端。
两者必须成对；均空按匿名模式请求，不使用AWS默认凭据链。本次匿名ListObjectsV2真实请求返回403 AccessDenied，无法确认桶内模板清单。
凭据需要ppts桶的s3:ListBucket权限；仅对象下载s3:GetObject权限不足。本次不修改桶策略、不上传/删除对象、不将桶改为公开。
系统环境优先于.env，接口每次读取；S3_ENDPOINT_URL无默认，空值503；桶默认ppts；区域默认us-east-1；超时默认20秒、范围(0,120]。
区域应匹配RustFS签名配置，不能留空。端点必须HTTP(S)根地址，不含凭据、路径或查询参数。
当前按用户提供HTTP地址接入，不自动改端口或协议；网络传输策略由实际部署负责。

## Postman操作

启动main.py，使用本机APP_HOST/APP_PORT，默认：

```text
GET http://127.0.0.1:8000/ppt-agent/v1/templates
```

Body选择none，不需要附件、message、purpose、模型配置或在Postman填写RustFS密钥。
RustFS凭据由后端读取。Params可选：

| 参数 | 默认/范围 | 含义与例子 |
| --- | --- | --- |
| prefix | 空，最多1024字符 | 桶内对象名前缀，如business/；不是任意关键词或本机路径 |
| max_keys | 100，1–1000 | 一页扫描对象数上限，包含非PPTX对象；不是返回模板总数 |
| continuation_token | 首次省略，非空且最多8192字符 | 上次响应游标原样传入，由Postman编码；不要自己生成 |

预期有权限时HTTP 200，示例数据仅用于解释字段，不是本次真实桶内容：

```json
{
  "bucket": "ppts",
  "items": [{
    "object_key": "business/简洁模板.pptx",
    "file_name": "简洁模板.pptx",
    "size_bytes": 123456,
    "last_modified": "2026-11-06T00:00:00Z"
  }],
  "returned_count": 1,
  "scanned_count": 1,
  "is_truncated": false,
  "next_continuation_token": null
}
```

仅列出.pptx（大小写不敏感），不把PPTX后缀当作兼容性或授权验证。
object_key完整保留目录，是后续选择标识；file_name只用于展示，允许同名。不拼接公共下载链接，私有桶不一定能匿名下载。
S3先分页，再过滤后缀，items可能少于max_keys，甚至空；is_truncated=true时仍需用next_continuation_token继续。
returned_count只代表本页，不代表桶内总数。last_modified来自S3、通常UTC，非本机时区猜测。

当前无权限的实际预期：HTTP 502（上游访问失败），而不是伪造空列表：

```json
{"detail": {"code": "storage_access_denied", "message": "无法列举模板桶，请检查RustFS访问凭据及s3:ListBucket权限。"}}
```

上游403映射502是因为后端访问存储失败，不能误认为是前端用户身份鉴权。
其他情况：配置无效503；桶不存在/存储网络失败502；存储分页游标无效400；Query范围不合法由FastAPI返回422。

## 断点、模块及资源归属

- api/routes/template_resource_routes.py：HTTP参数和安全错误映射；同步SDK在线程执行。
- api/template_resource_dependencies.py：Settings组装S3客户端，path模式endpoint/bucket，SigV4签名或明确匿名。
- integrations/storage/s3_template_catalog.py：ListObjectsV2及PPTX筛选，不读配置或依赖HTTP。
- domain/templates/template_resource_catalog_contract.py：目录协议与安全错误。
- models/templates/template_resource_response.py：列表条目、分页输出及安全错误字段。

建议在S3TemplateCatalog.list_resources里的list_objects_v2前后断点看参数和结果。不要将凭据/完整响应对象打印到日志。
SDK连接由外层closing关闭；不创建全局boto3客户端，不缓存用户结果。请求取消不会立即中止线程；连接/读取超时后资源释放，单次调用不自动重试。
日志templates.list_resources→storage.list_templates记录生命周期、父子操作和耗时；摘要仅扫描数、返回数和是否下一页，不记录桶对象名、游标、凭据或服务端错误原文。
boto3/botocore/s3transfer/urllib3的DEBUG已抑制，应用DEBUG不会启用签名请求转储。

## 选中后传入chat（最新实现）

前端不需要公开下载地址；将items中的object_key作为template_key传入POST /chat。
示例：{"message":"读取模板","template_key":"公司模板.pptx"}。返回template_read及template.content.blocks；不要再传template_url。
后端固定使用配置中的桶和S3地址，通过GetObject下载，凭据需要对象s3:GetObject权限。大小上限默认50 MiB，超限413；对象不存在404，不回退其他文件。
2026-11-06用户已成功列出8个PPTX；本轮真实chat读取公司模板及暑期模板均HTTP 200。此前匿名403属于历史验证，不代表当前填写凭据后的结果。详见[当前接口说明](接口调试说明.md)。
