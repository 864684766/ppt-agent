Agent 工具清单

按照能力分组；不是要求模型按固定顺序调用。

文档入口任务技术字段调试
当前12项有独立基础实现，但尚未接入真实Agent工具循环；生产数据、模板与产物登记也需要在宿主接线。ask_user当前仅保留部分数据定义，不是可调用工具。
分类工具与用途边界及调试
技能list_skills：发现技能；read_skill：读取SKILL.md不执行脚本或分析依赖；发现、读取。
联网search_web：搜索候选网页；fetch_webpage：读取选中页面正文搜索候选用URL交给fetch_webpage；candidate_id不能代替已登记资料的source_id。搜索不等于读取或核实；真实搜索依赖SearXNG。搜索、网页。
已导入资料list_materials：资料目录；search_materials：检索正文；read_material：读取定位内容资料可以来自上传或已导入网页，正式资料登记尚未接到chat；不是在线搜索。目录、检索、读取。
模板inspect_template：提取页面、母版、版式及对象；complete_template：按指定参考页复制补充；create_template_page：按明确方案绘制页面结构事实不等于角色判断；复杂对象、样式、视觉效果有限制。检查结构、补全、绘制。
成品build_presentation：按确认的页面计划生成；check_presentation：检查已登记成品生成支持文字、图片、媒体、表格、列表及常见原生图表；不自动选页或查事实。检查仅为基础版。生成、检查。

非工具和待接入能力

文件上传解析、OCR、PDF转换与渲染、视觉分析、日志、参数校验、模型工厂是模块或服务，不因被代码调用就视为模型工具。模板风格判断、大纲生成和用户问题应由Agent处理；ask_user的真实提问、等待和恢复随LangGraph开发。表格与列表单独工具已移除，绘制方法由build_presentation复用。

逐字段解释见字段清单与源码模型注释；每个工具的模型可见说明以其Schema与description为准。单元测试、真实模型工具选择和Office显示属于不同验证。
