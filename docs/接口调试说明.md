# 当前HTTP接口调试（2026-11-06）

当前验证“文件接收/内容解析＋OSS模板下载解析”，不调用AI，不返回SSE。模板使用列表中的object_key，通过template_key传入chat；原template_url字段已移除。

## 启动

在PyCharm运行根目录main.py，或：

```powershell
uv run --locked --no-sync python main.py
```

地址默认127.0.0.1:8000，使用.env的APP_HOST/APP_PORT。代码修改后重启服务，/docs应显示GET /ppt-agent/v1/templates和POST /ppt-agent/v1/chat。接口无debug前缀，不生成Postman集合。

## 先取得模板列表

```text
GET http://127.0.0.1:8000/ppt-agent/v1/templates
```

Body选none，结果items中的object_key就是要原样传给chat的template_key。例如公司模板.pptx；如果有目录，完整传入business/公司模板.pptx。
不是file_name、不是完整URL，不做URL编码，不需要前端持有RustFS密钥。分页说明见[列表说明](模板资源列表调试说明.md)。

## 只读取选中的OSS模板

```text
POST http://127.0.0.1:8000/ppt-agent/v1/chat
```

Body → raw → JSON：

```json
{
  "message": "读取这个模板的内容",
  "template_key": "公司模板.pptx"
}
```

预期HTTP 200：status=template_read，template_key回显；attachment=null；template包含object_key/file_name/format/size_bytes/content。
正文在template.content.blocks，PPT总页数在template.content.page_count；model_called=false。这个阶段只提取实际幻灯片文字/表格，不做角色判断、视觉或PPT制作。
当前真实验证公司模板.pptx为1053430字节、5页、15个文字块；不要把这些数量用于其他文件的固定期望。

## 同时上传参考资料和选择OSS模板

同一POST /chat，Body选择form-data：

| Key | 类型 | 示例 |
| --- | --- | --- |
| message | Text | 读取参考资料和模板，必填 |
| file | File | 选择本机资料，可选 |
| template_key | Text | 暑期生活规划通用PPT模板.pptx，可选 |

不传purpose或template_url；不要手动设置Content-Type，由Postman自动生成multipart边界。
提供两份文件时status=files_read；attachment是本机上传资料的解析结果，template是OSS模板解析结果，不会混在一起。
任一读取失败返回明确错误，不把部分读取伪装成整个请求成功；未提供template_key不会访问OSS。
只传file时仍为attachment_read；只传message时为message_received，attachment/template均null，不调用AI。

## 返回状态与错误

| status | 含义 |
| --- | --- |
| message_received | 未提供文件，仅接收消息 |
| attachment_read | 仅解析了上传附件 |
| template_read | 仅下载并解析了OSS模板 |
| files_read | 两者都已完成读取 |

文件读取成功不等于OCR/AI分析成功。模板无文字页看pages_without_text和warnings。
404 template_not_found：Key不存在，刷新列表后复制完整object_key；422 template_format_invalid：不是PPTX对象；413 template_too_large：OSS模板超过专用上限；502 storage_access_denied：缺少GetObject权限；其他内容校验或解析错误见[附件说明](对话附件读取调试说明.md)。
原template_url作为额外字段不再接受，返回4xx；不是为了兼容旧接口而继续下载任意URL。

## 配置与断点

本机.env中的S3_ENDPOINT_URL=http://124.71.135.104:8081、S3_TEMPLATE_BUCKET=ppts；凭据仅后端读取。
ListBucket是列举权限，GetObject是读取对象权限，能列举不等于一定能下载。
S3_TEMPLATE_MAX_FILE_BYTES默认52428800（50 MiB），范围1024–209715200；与普通上传20 MiB分开，覆盖列表中约39 MB的模板。Office展开上限及DOCUMENT_MAX_*仍独立生效，超限明确失败。

断点顺序：chat_routes.chat → chat_template_processing.read_chat_template → S3TemplateFileReader.read_file中的get_object/Body.read → chat_attachment_processing.validate_and_read → PptxDocumentReader.read。
OSS下载和PPTX解析为不同模块；复用已有内容校验及读取器，无模型调用。SDK客户端、下载Body流在线程内关闭，原始字节仅本次请求内使用、不归档；取消等待不保证立即停止线程。
响应头X-Request-ID关联log中的请求与下载/解析操作。日志不记录对象标识、正文、密钥；记录字节数、页数、块数和安全异常位置。
