当前约定：产品最终包含前端和后端；当前阶段只开发后端，以 API 和自动化测试承载交互能力。文中界面是未来产品需求，并非本阶段前端开发承诺。

1. 目标与范围

项目以学习和贯通 LangChain、LangGraph、LangSmith、FastAPI 与 DeepSeek Harness 为重要目标，同时形成可运行的 PPT 生成后端。用户输入主题、资料和需求后，先与 AI 共创大纲，再生成可在 PowerPoint 或 LibreOffice 中打开的 PPTX。

默认结果：8–12 页，包含封面、目录、主要内容和来源页；默认页数包含这些页面。章节页与结尾页按内容和用户选择确定。文字、形状及适用图表尽量保留原生可编辑性；复杂模板的可编辑程度以兼容性结果为准。

本期后端范围暂不纳入
项目及会话、大纲版本、文件上传、资料分析、模板识别与映射、用户问题、生成任务、预览与下载、技能加载、模型配置、追踪和测试。前端页面开发、在线模板搜索、多人协作和身份体系；扫描件 OCR、复杂动画与任意模板无损适配不作为首版承诺。

2. 产品运行流程

输入主题及要求上传资料／选择联网AI 生成大纲对话或手动编辑确认大纲与模板生成和预览下载或继续修改

用户可以只使用本地资料、只使用联网资料或组合使用。联网搜索用于内容调研；首版不搜索在线模板。AI 应记录可追溯来源，资料不足时主动说明。

大纲确认

大纲以有稳定标识的条目保存，支持修改文字、增删、排序、合并及拆分，也支持通过对话提出修改。用户确认前不进入最终生成。对话修改应基于最新版本，并返回修改结果；同时编辑造成版本冲突时，提示用户处理，不能静默覆盖。

生成后修改

用户可指定单页或全局调整内容、背景和风格。要求不明确时，AI 提出可回答的问题，例如选择简洁商务、科技或学术风格，也可接受自由文字。修改生成新版本，旧版本可回看和下载。

3. 功能需求

能力行为验收重点
项目与对话按项目保存消息、资料、技能、模板、大纲和生成版本。第一阶段保留输入输出文件；重启后恢复对话与任务属于后续阶段。
资料与来源支持 PDF、DOCX、TXT、Markdown；联网搜索由可替换服务提供。保留网页和文件引用。页面或来源页能追溯到 URL、文件名及可获得的页码／片段；不虚构来源。
大纲共创每条包括页面意图、标题、要点及关联来源；对话和直接编辑作用于同一版本。合并、拆分、排序、撤销／恢复及确认均可通过后端接口完成。
生成与预览基于确认的大纲及模板生成 PPTX、页面预览和检查报告。符合页数与必需页面约束；可打开；主要文本可编辑；异常可见。
人工介入遇到模板角色不确定、页面缺失、资料不足或风格不明确时发问。支持选项和自由输入；任务可在当前进程内暂停并继续；跨重启恢复放在后续阶段。
任务与版本查看进度、取消、失败原因、输出版本及下载地址。取消、失败、重试不覆盖已完成文件；跨重启恢复任务属于后续阶段。

4. 模板与技能

模板

首版提供少量经过授权和兼容性验证的内置模板，支持用户上传模板，不提供在线模板搜索。上传后输出页面或版式预览及建议用途；用户可指定封面、目录、章节、内容、结尾、来源等角色并保存映射。

例如只上传三页模板，系统应说明已识别和缺失的页面，并让用户选择补充上传、复用现有版式、AI 按风格补全，或在允许时省略可选页面。AI 补全生成风格相近的新页面，不承诺完全复刻复杂设计。.potx 支持以原型验证为准。

主题技能

支持用户创建、上传、启停和热加载技能包。技能以 SKILL.md 为入口，可包含脚本、参考资料和资源；运行时按技能说明读取资料、调用所需脚本。新增或更新对新任务生效，运行中的任务固定使用启动时的技能版本。

例如律师技能可定义法域、论证结构和引用规则；具体法规和案例仍需从可追溯的资料获取。外部技能可能需要依赖、工具或环境变量，导入时应显示兼容性及执行权限；不兼容时明确反馈。

5. 当前后端交付

  1. 提供项目、会话、文件、大纲、模板、技能、问题、任务、版本和下载 API；使用 API 文档供调试。
  2. LangGraph 负责状态与人工介入；LangChain 模板识别子智能体与 Harness 模板使用子智能体分工运行。
  3. 提供本地运行配置和不含密钥的配置示例；第一阶段使用本地文件和内存状态，数据库后续引入。
  4. 提供可用的任务状态与事件流，未来前端可连接；本期使用接口或 API 客户端验证流程。

模型可按任务配置；用户已确认百舸代理的基础对话、结构化输出与工具调用可用，首阶段不重复验证这些基础能力。不同模型的任务效果与 Harness 代理接入仍需评估。

6. 验收、阶段与待定

首版端到端验收

  1. 通过 API 创建项目并上传至少一种本地资料，生成有来源的大纲；支持对话修改、直接修改、合并与确认。
  2. 上传或选择模板，识别候选页面；对不确定或缺失角色产生可回答的问题，保存用户映射。
  3. 用已确认大纲和映射生成 8–12 页 PPTX，包含封面、目录、内容和来源页；可以打开且主要文本可编辑，提供预览。
  4. 对已生成 PPT 提出修改，必要时回答澄清问题，生成新版本并保留旧版本。
  5. 导入包含脚本的示例技能，加载指定版本并按说明执行；记录执行结果与兼容性。

阶段建议

① Windows 本机后端：完整大纲对话编辑、上传完整或残缺模板、识别及人工反馈、Harness 接入和生成可打开的 PPTX；支持内置简洁模板 → ② 增强资料、来源和技能 → ③ 完善生成后修改与质量检查 → ④ 引入数据库、跨重启恢复及多任务能力。第一阶段从主题生成和反复修改大纲，不以固定大纲代替；模板缺失时可让用户补充或选择 AI 补全。

待讨论：并发规模、首批模板来源与许可、联网搜索服务、具体模型和视觉能力、PPT Master 的集成方式、各类模板的兼容范围。原型结论出来后再冻结实现承诺。
