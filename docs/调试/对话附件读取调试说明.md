# 对话附件读取

POST /ppt-agent/v1/chat/stream 的 multipart/form-data 字段为必填 message、可选 file 和可选 template_key。文件支持 TXT、MD、PDF、DOC、DOCX、XLSX、PPTX，复用现有格式校验与读取器；不接收 purpose。Postman 请让程序自动生成 Content-Type 边界。

接口根据 message 和附件事实选择资料分支；选择文件时才解析并提炼，attachment_analyzed 表示提炼是否完成。结果不回显附件正文；summary_inputs 包含文件块来源。template 返回所选 OSS 模板的解析结果，但不参与资料汇总。状态和完整 Postman 操作见[接口说明](接口调试说明.md)。

文件大小及 Office 展开限额分别由 UPLOAD_MAX_FILE_BYTES 和 UPLOAD_MAX_UNCOMPRESSED_BYTES 控制；正文规模由 DOCUMENT_MAX_* 控制。PDF 无文字页可使用本地 OCR，识别不保证准确。解析失败返回对应错误，不把部分内容伪装成成功。

DOC 文件依赖已配置且可访问的 Gotenberg 服务转换为 PDF，转换后的页码可能与原文不同；空配置或服务失败时明确报错。原文件大小及转换结果 50 MiB 上限均生效。

普通附件默认原文件上限256 MiB、Office累计展开上限512 MiB；可通过.env调整（两项各不超过1 GiB）。较大文件会增加读取、解析及模型处理的内存和耗时；此配置不代表PPT的图片或视频已参与文本提炼。
