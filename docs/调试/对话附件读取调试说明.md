# 对话附件读取

POST /ppt-agent/v1/chat/stream 的 multipart/form-data 字段为必填 message、可选 file 和可选 template_key。文件支持 TXT、MD、PDF、DOCX、XLSX、PPTX，复用现有格式校验与读取器；不接收 purpose。Postman 请让程序自动生成 Content-Type 边界。

接口现在会根据 message 执行联网网页研究；attachment 返回本次附件读取结果，attachment_analyzed=false 表示附件还未交给模型，也没有与网页资料合并。template 返回所选 OSS 模板的解析结果，也不参与网页研究。状态和完整 Postman 操作见[接口说明](接口调试说明.md)。

文件大小及 Office 展开限额分别由 UPLOAD_MAX_FILE_BYTES 和 UPLOAD_MAX_UNCOMPRESSED_BYTES 控制；正文规模由 DOCUMENT_MAX_* 控制。PDF 无文字页可使用本地 OCR，识别不保证准确。解析失败返回对应错误，不把部分内容伪装成成功。
