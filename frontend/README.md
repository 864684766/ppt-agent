# 静态前端演示

React、TypeScript、Vite 和 Tailwind CSS 构建的独立前端；`src/components/ui` 中的按钮采用 shadcn/ui 的项目内源码模式。模板、进度、大纲和提问均为 `src/data` 或组件内的演示数据，不调用后端，也不保存数据。示例大纲占据主工作区，可通过顶部切换查看对话，底部输入框始终保留。选择模板、添加或移除附件、发送本地消息和填写示例回答可交互；生成按钮暂不可用。刷新后本地状态会清空。

## 启动与构建

使用 Node.js 22.12 或更高版本（本次构建使用 24.22.3）及 npm，在此目录执行：

```powershell
npm ci
npm run dev
npm run build
```

按终端显示的地址打开页面。现有机器的 Node 14 不满足 Vite 8 要求；请先切换到满足要求的 Node 版本。依赖具体版本由 `package-lock.json` 锁定。2026-11-26 查询 npm 官方源并安装；使用的是 npm 当时的 latest 发布标签，并非对各包预发布版本的完整调查。

## 代码组织及后续接入

- `src/components/ui/`：可复用基础组件。
- `src/components/`：模板、聊天及大纲面板；页面由 `App.tsx` 组装。
- `src/data/demo.ts`：示例模板与大纲，不是接口契约。

后续应先确定后端 SSE、提问恢复及大纲的真实契约，再用适配层替换演示数据，处理流结束、错误、取消和资源清理。当前示例提问不提交服务器；上传文件也不会离开浏览器。

“新建会话”会清空当前页面中的消息、附件、回答和输入，恢复默认模板并显示空白对话；目前没有会话持久化，示例大纲不会出现在新会话中。模板列表在桌面端纵向滚动，窄屏横向滚动。

左侧模板面板可通过顶部按钮折叠和展开；折叠状态仅保存在当前页面，刷新后恢复展开。
