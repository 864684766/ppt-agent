# 前端工作台

React、TypeScript、Vite 与 shadcn/ui 项目内组件构建。聊天接入 `/ppt-agent/v1/chat/stream`，模板列表接入已有 `/ppt-agent/v1/templates`，模板缩略图为装饰图形，并非真实 PPT 页面预览。

## 启动

先在项目根目录运行 `uv run --locked --no-sync python main.py`。另开终端，使用 Node.js 22.12 或更高版本（直接运行 TypeScript 的测试命令使用 Node.js 24）：

```powershell
cd frontend
npm ci
npm run dev
npm run build
node --test tests/client.test.mjs tests/mergeOutline.test.mjs
```

开发服务器将 `/ppt-agent` 代理到 `http://127.0.0.1:8000`；后端地址或端口变化时需修改 `vite.config.ts`。生产部署需要同源代理该路径，Vite 预览服务器本身不提供后端代理。锁定版本以 `package-lock.json` 为准。

## 使用与限制

输入非空消息，可选一个 txt、md、pdf、doc、docx、xlsx 或 pptx 附件。模板可选，列表从对象存储读取所有分页；选中后按原样传递 object_key，后端会下载解析。存储访问失败时显示错误并可重试，不使用演示模板。缩略图为占位图。

处理过程中显示后端实际 progress 事件：最新阶段逐字出现并以渐变标识运行状态，结束或中断时停止动画；系统启用减少动态效果时直接显示完整文字。thinking 按实际收到的文本增量显示，每段短暂淡入，不被阶段动画延迟。需在后端 `.env` 设置 `LLM_SHOW_THINKING=true` 并重启服务，且模型供应商必须返回支持的推理内容。大纲预览可手动查看，最终返回大纲时自动切换，顶部可切回聊天记录。中断时返回的草稿和错误也会显示。

本轮结束后可在大纲面板编辑整份标题、页面标题及已有要点，切换视图会保留修改。编辑只存在当前页面，不提交给后端；刷新或新建会话后不保留。续轮返回时保留已有页面，按要点来源编号追加未出现过的内容；同一轮预览从上轮大纲重新合并，不反复追加。后端续轮会重新编排历史资料，相同编号的内容不会再次追加；不同编号的语义重复内容仍需人工检查。生成期间预览为只读。修改文字后原来源编号仍保留，但尚未重新验证来源与新文字的对应关系。

本轮没有大纲且处理失败时可重试，沿用原消息、附件、模板和上一轮编号；文件只保存在当前页面内。已有大纲的模型整理失败提示不在界面显示，后端返回的故障字段仍保留在响应中。重试会再次调用模型，可能产生费用。

每轮成功结果的 task_id 用于下一轮补充资料；检查点只存在服务进程内，重启后失效。后端目前没有公开原问题的选项恢复 HTTP 接口；用户可以通过输入框发起新一轮补充，不能将其视为对原问题的正式选项回答。停止按钮会中止连接，底层线程中的文件解析可能继续。新建会话清除页面中的当前对话和选择并取消正在等待的请求；刷新后状态不保留。

`src/api/` 包含接口类型、模板分页和 SSE 解码；`src/components/` 分别负责聊天、大纲和模板展示。左侧面板支持折叠及减少动态效果设置。尚未接入 PPTX 生成或下载。

大纲面板提供“构建 PPT”入口；当前没有对应的 HTTP 构建接口，按钮禁用并标明尚未接入。前端编辑的大纲尚未提交后端。
